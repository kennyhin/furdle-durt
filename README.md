# furdle durt — organic rock

Single-page band site: black hero, logo, and a plant button that waters itself before opening upcoming shows.

## Local preview

```bash
python3 -m http.server 5173
```

Open http://localhost:5173

## Edit show dates

Update the list inside `index.html` in the `#shows-modal` section.

## GitHub Pages

This repo is meant to publish from the `kennyhin` account (same as athletic-director-hub), as a **separate** repo — typically:

`https://kennyhin.github.io/furdle-durt/`
